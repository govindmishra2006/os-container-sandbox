Where the disk head goes

Containers share one disk. Each algorithm below orders the same queue of cylinder requests; the trace shows the read/write head travelling from the start position to every request. Less travel means less seek time.

Virtual disk

64 blocks of 16 bytes. The bit table holds one bit per block: 0 is free, 1 is in use. Create files with each allocation method, then crash the disk halfway through a write and recover it from the journal.

      Containers

      Guests run as ordinary processes on the shared kernel. The heartbeat monitor watches them and restarts any that crash, up to a restart budget.

      Crash and restart

      Starts “web”, which crashes after a quarter second, and “db”, which stays healthy. Takes about two seconds.

        User mode and supervisor mode

        A guest tries to set the hostname directly, which faults, then asks the kernel through a system call.

          Threats

          The security monitor sorts violations into the five classic categories. Simulated attacks include denied reads and writes, a request flood, a CPU quota overrun, password guessing and a process lying about its domain.
